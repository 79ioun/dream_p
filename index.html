주인공

외모 모든 장면에 같은 문장으로 들어갑니다

목록에서 고르거나 아래 칸에 직접 쓰세요. 직접 쓴 내용이 우선하며, 영어 프롬프트에는 입력한 그대로 들어갑니다.

의상

시기별 의상을 직접 쓸 수 있어요. 비워 둔 시기는 나이대에 맞춰 자동으로 정해지고, 상징 색상이 포인트로 유지됩니다. 직접 쓴 내용은 영어 프롬프트에 그대로 들어갑니다.
약 1분 영상에 맞춘 이야기입니다. 주인공은 미래의 나이며, 현재의 나에서 성장하는 과정, 노력과 시련, 꿈을 이룬 모습, 마지막 다짐까지 이어집니다. 입력한 꿈 내용이 반영되고, 장면 나누기는 이미지 프롬프트 단계에서 이뤄집니다. 버튼을 누를 때마다 사건과 장소가 다르게 구성됩니다.
버튼을 누르면 시나리오가 만들어집니다.

자동으로 구성되는 내용

  1. 기승전결의 흐름에 맞춰 장면이 하나의 이야기처럼 자연스럽게 연결되도록 구성됩니다.
  2. 각 장면에 어울리는 장소, 주변 환경, 시간대, 조명 등이 구체적으로 표현됩니다.
  3. 모든 장면에서 동일 인물로 표현하고 얼굴형, 눈동자 색, 헤어스타일, 얼굴 특징을 일관되게 유지합니다.

만드는 방법

  1. 꿈과 관심사를 입력합니다.
  2. 장르와 스타일을 고릅니다.
  3. 주인공을 만듭니다.
  4. 시나리오를 만듭니다.
  5. 장면 수와 화면 비율을 정합니다.
  6. 프롬프트를 복사해 이미지 생성 AI에 붙여 넣습니다.
  7. 인트로 이미지 프롬프트도 만들어 봅니다.

개인정보 안내

이 페이지는 입력한 내용을 서버로 전송하거나 저장하지 않습니다. 이름, 학교명, 연락처 같은 개인정보는 입력하지 않는 것을 권장합니다.
